# 🧠 AI-Powered Resume Scanner

An AI-powered web application that analyzes resumes and provides intelligent feedback based on job descriptions using Google's Gemini API.

The application evaluates a candidate's skills, experience, and overall suitability for a role, helping users optimize their resumes and improve their chances of passing initial screening processes.

## 🚀 Live Demo

**Try it here:**
https://resume-scanner-sl3z.onrender.com

> **Note:** The project uses the free tier of the Gemini API, which comes with daily request limits. If the application is unavailable or returns an error, the API quota may have been exhausted. In that case, please try again later or run the project locally.

---

## ✨ Features

* 📄 Upload resumes in PDF format
* 🤖 AI-powered resume analysis using Gemini API
* 🎯 Compare resumes against specific job roles
* 📊 Evaluate skills, experience, and relevance
* 💡 Receive actionable suggestions for improvement
* ⚡ Instant feedback through a simple web interface

## 📷 How It Works

1. Upload your resume.
2. Enter the target job role or description.
3. The Gemini model analyzes the resume content.
4. Receive:

   * Resume evaluation
   * Skill assessment
   * Job-role relevance score
   * Improvement suggestions
